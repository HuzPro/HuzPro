## Now

- **Agents for small and medium businesses.** Support agents over email and voice, lead trackers, ad-account audits. Scoped with the customer, live on dev first, then prod once it checks out.
- **The platform they run on.** The plumbing those agents need to do real work: a self-hosted OAuth broker so an agent can act in a customer's Google, HubSpot or Notion account, a credential manager, per-project email, and the deploy pipeline every agent ships through.

## Open source

- [**pytest-lanes**](https://github.com/HuzPro/pytest-lanes). Runs a pytest suite as one subprocess per lane, so suites that share a database container, a fixed port or session state get parallelism without being made concurrency-safe.
- [**pytest-uia**](https://github.com/HuzPro/pytest-uia). Drives real Windows apps from pytest through the UI Automation tree instead of screenshots.
- [**tk-uia**](https://github.com/HuzPro/tk-uia). One call makes a Tkinter app's widgets show up to Windows accessibility clients as named, operable controls.
- [**truemic**](https://github.com/HuzPro/truemic). A one-day hackathon build: a virtual mic that only lets your enrolled voice through, with a watermark a receiver can check.
